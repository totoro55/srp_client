# Контракт для расчёта мотивации

Приложение эти данные только читает. Пока таблицы и вьюшек нет, экраны расчёта не показываются.

## Дополнительные данные сотрудника

Отдельная таблица, не `dictionaries.employees`. Имя схемы можно согласовать. Состав такой:

- `employee_uuid` — сотрудник
- `period` — первое число месяца
- признак участия в сдельной оплате по умолчанию: истина это КТУ+, ложь это КТУ−
- уровень оплаты, базовая премия, часовая ставка и прочие ставки

Ключ — сотрудник и месяц. Если месяца в таблице не будет, приложение возьмёт текущую строку на любой открытый месяц и историю ставок не покажет.

## Вьюшки расчёта

Имена колонок примем, когда вьюшки будут готовы. Нужны три результата:

- свод филиалов территории за месяц
- сотрудники филиала за месяц: бригада, сумма и короткий состав
- строки детализации премии одного сотрудника за месяц

Обзор тарифов филиала эти вьюшки не заменяет: там сохранённые ставки и коэффициенты, здесь суммы.
