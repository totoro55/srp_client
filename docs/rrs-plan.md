# План по корзинам на РРС

Карточка территории, мастер создания и таблица параметров уже есть. Пункты ниже записаны и пока не делаются.

## Доработать таблицу подключённых корзин

Таблица на карточке РРС: колонка — корзина, подзаголовок — параметр, значения в одной строке. Правка включается отдельно, версия меняется через диалог. Следующий проход — сделать эту таблицу удобнее для набора подключённых корзин. Состав доработки ещё не зафиксирован.

## Просмотр истории

При правке того же месяца уже пишутся `basket_connections_log` и журнал строк версии в `basket_data`. Нужен просмотр: какая версия и какие параметры действовали на территории по месяцам и что меняли внутри месяца.

## Экспериментальные корзины на выбранных территориях

Тестовая версия сейчас доступна любой РРС при подключении. Нужна возможность включить экспериментальную корзину только на явно выбранных территориях.

## Вьюшка версии со стороны разработчика

Разработчик в каталоге привязывает к версии корзины конкретную вьюшку для расчёта. Это не настройка РРС: привязку задают на версии, рядом с параметрами. Расчёт премий по этой вьюшке пока не строится.
