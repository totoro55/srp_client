# Таблицы, которые заполняются снаружи

Список снят с живых таблиц. Приложение эти таблицы только читает. Примеры — реальные строки.

У `territories`, `branches` и `employees` нет колонок `created_at` и `updated_at`. Пометка `deleted` приходит с загрузкой справочника. Помеченные филиал и территория остаются в списке месяца, только если на этот месяц для них уже есть записи, и к ним нельзя подключить новое участие, карточку или назначение. Помеченного сотрудника не предлагают для нового правила, упоминания и назначения. Уже сохранённые имя и правило по этому логину остаются.

## dictionaries.territories

Территория. Ключ `uuid`, `code` уникален.

| Поле | Тип | Пусто | Смысл |
| --- | --- | --- | --- |
| name | text | нет | Название |
| code | text | нет | Код, уникальный |
| uuid | uuid | нет | Ключ |
| deleted | boolean | нет | Пометка на удаление, по умолчанию `false` |

```text
name: див. Юг (ДОП)
code: EY00055
uuid: 7c4251dd-6d3d-11eb-a233-00155d28220e
```

## dictionaries.branches

Филиал. Ключ `uuid`, `code` уникален. `name` не уникален. `territory_uuid` ссылается на `territories.uuid`.

| Поле | Тип | Пусто | Смысл |
| --- | --- | --- | --- |
| name | text | нет | Название филиала |
| code | text | нет | Код, уникальный |
| territory_uuid | uuid | нет | Территория |
| uuid | uuid | нет | Ключ |
| deleted | boolean | нет | Пометка на удаление, по умолчанию `false` |

```text
name: Батайск Кирова 11А
code: 387
territory_uuid: 0c083cef-3607-11ea-a20d-00155d28220e
uuid: ab5802e6-0a39-4698-bd40-3d17b94b5327
```

## dictionaries.employees

Сотрудник. Ключ `uuid`. Уникальны `code` и `login`. `territory_uuid` ссылается на `territories.uuid`, `branch_uuid` — на `branches.uuid`. Названия территории и филиала берутся из этих справочников. У системной записи (сайт, доставка, система) территории и филиала нет: в выгрузке нули, в таблице пусто. Под такой записью вход не выполняется, логин технический. Документы при этом проводятся от её имени.

| Поле | Тип | Пусто | Смысл |
| --- | --- | --- | --- |
| uuid | uuid | нет | Ключ |
| code | text | нет | Табельный код, уникальный |
| name | text | нет | ФИО |
| title | text | нет | Должность |
| territory_uuid | uuid | да | Территория. Пусто у системной записи |
| branch_uuid | uuid | да | Филиал. Пусто у системной записи |
| login | text | нет | Логин. У системной записи технический, для входа не используется |
| deleted | boolean | нет | Пометка на удаление, по умолчанию `false` |

```text
uuid: 17dfb654-d901-43ec-8004-b1bdf68a8ef4
code: AR10791
name: Куценко Анастасия Александровна
title: Универсальный сотрудник магазина
territory_uuid: 0c083cef-3607-11ea-a20d-00155d28220e
branch_uuid: ab5802e6-0a39-4698-bd40-3d17b94b5327
login: Kucenko.AA
```

```text
uuid: bbd5fddb-df60-11ef-92d2-0050569d9cb8
code: GH01535
name: Сайт ДНС Быстрая продажа
title: Система
territory_uuid:
branch_uuid:
login: bbd5fddb
```

## dictionaries.product_categories

Категория товара. Ключ `uuid`. `parent_1` — ближайшая папка, `parent_3` — верхняя. `created_at` база ставит сама (`now()`), в загрузке его можно не передавать.

| Поле | Тип | Пусто | Смысл |
| --- | --- | --- | --- |
| uuid | uuid | нет | Ключ |
| name | varchar(255) | нет | Название |
| parent_1 | varchar(255) | да | Ближайшая папка |
| parent_2 | varchar(255) | да | Папка выше |
| parent_3 | varchar(255) | да | Верхняя папка |
| created_at | timestamptz | нет | Время появления строки, по умолчанию `now()` |

```text
uuid: e8988d6e-61c2-11e5-8003-00155d03361b
name: Bluetooth клавиатура и мышь
parent_1: 01. Возврат из не использовать
parent_2: 99. Возврат из не использовать
parent_3: 20. Категории на утилизацию
created_at: 2026-10-15 16:00:32.371887+03
```

## dictionaries.product_kinds

| Поле | Тип | Пусто | Смысл |
| --- | --- | --- | --- |
| uuid | uuid | нет | Ключ |
| name | varchar(255) | нет | Название |
| parent_1 | varchar(255) | да | Ближайшая папка |
| parent_2 | varchar(255) | да | Папка выше |
| parent_3 | varchar(255) | да | Верхняя папка |
| created_at | timestamptz | нет | Время появления строки, по умолчанию `now()` |

```text
uuid: f691ed87-6188-11e5-8003-00155d03361b
name: Видеоняня
parent_1: 05. Переносные аудио/видео устройства
parent_2: 02. Аудио-видео оборудование
parent_3: 08. Аудио-видео товары
created_at: 2026-10-15 16:00:32.371887+03
```

## raw.basket_category_stats

Статистика категории. Ключ: `territory_uuid`, `period`, `category_uuid`. `period` — первое число месяца выгрузки. `avg_price` и `sum_quantity` могут быть пустыми. `territory_uuid` ссылается на `territories.uuid`, `category_uuid` — на `product_categories.uuid`, поэтому справочник грузится раньше. `loaded_at` база ставит сама.

| Поле | Тип | Пусто | Смысл |
| --- | --- | --- | --- |
| territory_uuid | uuid | нет | Территория |
| category_uuid | uuid | нет | Категория |
| period | date | нет | Месяц выгрузки, первое число |
| avg_price | numeric | да | Средняя стоимость |
| sum_quantity | numeric | да | Сумма штук |
| loaded_at | timestamptz | нет | Время загрузки, по умолчанию `now()` |

```text
territory_uuid: e6288bee-40c2-11e1-8064-001517c526f0
category_uuid: ea42626b-778a-11e5-9edf-00155d03361b
period: 2026-10-01
avg_price: 517
sum_quantity: 752
loaded_at: 2026-10-15 16:00:32.371887+03
```

## raw.basic_bonuses

Базовая премия филиала за месяц. Ключ: `branch_uuid`, `period`. `period` — первое число месяца. `branch_uuid` ссылается на `branches.uuid`. `base_bonus` приходит текстом, как в выгрузке. Непустая премия за выбранный месяц разрешает подключить филиал к мотивации. Фиксированная премия сотрудника за этот месяц вычитает её из уровня оплаты труда.

| Поле | Тип | Пусто | Смысл |
| --- | --- | --- | --- |
| branch_uuid | uuid | нет | Филиал |
| base_bonus | varchar(255) | нет | Базовая премия |
| period | date | нет | Месяц, первое число |

```text
branch_uuid: c4e12c65-f0bf-485a-b329-975465881a9e
base_bonus: 39009.4
period: 2026-10-01
```

## raw.hr_ktu

Штатное расписание сотрудника за месяц. Ключ: `period`, `employees_uuid`, `date_modified`. Внешних ключей нет: uuid сотрудника и филиала лежат текстом. У одного сотрудника за месяц бывает несколько строк. Текущая строка месяца — с наибольшей `date_modified`. `probation` и `ktu` бывают пустыми.

| Поле | Тип | Пусто | Смысл |
| --- | --- | --- | --- |
| period | date | нет | Месяц, первое число |
| employees_uuid | text | нет | Сотрудник, uuid текстом |
| branch_uuid | text | да | Филиал, uuid текстом |
| title | text | да | Должность |
| probation | boolean | да | Испытательный срок. Пустое значение читается как нет |
| ktu | boolean | да | Истина — КТУ+, ложь — КТУ−. Пустое значение читается как КТУ− |
| hourly_rate | float8 | да | Часовая ставка с НДФЛ 13%. Перед окладом налог вычитается |
| salary_amount | float8 | да | Уровень оплаты труда |
| date_modified | date | нет | Дата версии строки |
| status | text | да | Работающий, Длительное отсутствие или Уволен |

## raw.sale

Строка продажи. Одна таблица на корзины продажи и выдачи. Внешних ключей нет. Повторная загрузка заменяет месяц целиком, уже загруженные месяцы не стираются. Совсем старый период, четыре–пять лет, можно удалить, если таблица станет слишком большой. `author` — кто продал, `author2` — кто выдал. Имя колонки `kinde` остаётся как в выгрузке. В выгрузке приходит `contragent_type`. В таблицу пишется `b2b`: истина для контрагентов `462d4d24-7fe3-401a-a24c-6f595156845b` и `1e8123a5-c7b3-4496-b49d-5efe3ed05c8b`, иначе ложь.

| Поле | Тип | Пусто | Смысл |
| --- | --- | --- | --- |
| period | timestamp | да | Месяц документа, первое число, полночь |
| firm_uuid | uuid | да | Филиал |
| author | text | да | Кто продал, uuid текстом |
| author2 | text | да | Кто выдал, uuid текстом |
| b2b | boolean | да | Безнал. Истина только для двух контрагентов безнала |
| link_doc | text | да | Ссылка на документ |
| date | timestamp | да | Дата и время документа |
| document_number | text | да | Номер документа |
| kinde | text | да | Вид изделия, uuid текстом |
| category | text | да | Категория, uuid текстом |
| brend | text | да | Бренд |
| name_product | text | да | Название товара |
| price | float8 | да | Цена |
| count | float8 | да | Количество |
| volume | float8 | да | Объём |
| type_document | text | да | Вид документа. Продажу и выдачу не разделяет |

## raw.grafiki_tabeli

День графика и табеля сотрудника на филиале. Внешних ключей нет. Один день может прийти несколькими строками: часы графика, часы табеля и нулевая копия. Первичного ключа нет. Для месяца приложение схлопывает день до максимума каждого показателя и складывает часы. `norma_hour` — график, `fact_hour` — табель. Оклад на экране филиала — часовая ставка из `raw.hr_ktu` без НДФЛ 13%, умноженная на сумму `fact_hour`. Имя колонки `noma_day` остаётся как в выгрузке.

| Поле | Тип | Пусто | Смысл |
| --- | --- | --- | --- |
| period | timestamp | да | Месяц, первое число, полночь |
| date | timestamp | да | День |
| branch_uuid | uuid | да | Филиал |
| employees_uuid | uuid | да | Сотрудник |
| noma_day | float8 | да | Норма дней графика |
| fact_day | float8 | да | Факт дней по табелю |
| norma_hour | float8 | да | Часы графика за день |
| fact_hour | float8 | да | Часы табеля за день |
